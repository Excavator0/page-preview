# page-preview

Браузерный веб-компонент `<page-preview>`. По адресу из атрибута `src` загружает HTML-страницу и показывает карточку со ссылкой, названием документа и первым заголовком `h1`.

## Импорт

Корневой импорт сам регистрирует элемент. Дополнительный вызов `register()` не нужен:

```js
import '@excavator0/page-preview';
```

```html
<page-preview src="/pages/example.html"></page-preview>
```

Обычный браузер не понимает голое имя пакета. В своей странице подключайте файл напрямую:

```html
<script type="module" src="./src/page-preview.js"></script>
```

Либо установите пакет и откройте его через сборщик или import map:

```js
import '@excavator0/page-preview';
```

## Поведение

- `src` — адрес HTML-документа. Относительный адрес разрешается от адреса страницы, на которой стоит компонент.
- В открытом Shadow DOM есть ссылка `a[part="link"]`. Её `href` ведёт на разрешённый адрес `src`, а текст ссылки содержит название документа или сам адрес.
- `span[part="title"]` содержит `document.title.trim()`. Если названия нет, текст: `Название отсутствует`.
- `span[part="heading"]` содержит `textContent.trim()` первого `h1`. Если заголовка нет, текст: `Заголовок отсутствует`.
- На элементе `<page-preview>` стоит `data-status="loading"`, `data-status="ready"` или `data-status="error"`.
- Ошибка HTTP, сбой сети и пустой `src` переводят карточку в `error` и не оставляют необработанное исключение.
- Смена `src` загружает новую страницу. Ответ более старого запроса не перезаписывает новые данные.
- Несколько карточек работают независимо. Если элемент снят со страницы до ответа, этот ответ его не обновляет; после повторного подключения карточка снова загружает страницу.
- Название и заголовок выводятся как текст, без `innerHTML`.

## Локальная проверка

Из корня проекта:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/demo/ . В каталоге `demo/example.html` заданы название «Пробная страница» и заголовок «Первый заголовок». Вторая карточка запрашивает отсутствующий файл и переходит в состояние ошибки.
